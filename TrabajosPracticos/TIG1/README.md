# TIG1 - Despliegue de Software

## Descripción

Trabajo de Investigación Grupal sobre el despliegue de software para un evento global en un videojuego online. Corresponde al escenario 7: sincronización simultánea de cliente y servidores regionales.

La presentación del grupo desarrolla la problemática, la estrategia Blue-Green con Feature Flags, los roles y el flujo del proceso, el soporte de SCM y DevOps, la seguridad, el plan de release y la arquitectura de infraestructura.
