# TP4 - SCM - Herramientas de SCM

## Descripción

Trabajo Práctico evaluable de la Unidad 3 (Gestión del Software como producto), orientado a
la aplicación práctica de los conceptos de Administración de Configuración de Software (SCM)
mediante una herramienta de control de versiones.

El trabajo consiste en diseñar e implementar la estructura de este mismo repositorio,
definir las reglas de nombrado de los Ítems de Configuración, y establecer el criterio para
la creación de Líneas Base.

## Contenido de la carpeta

| `TP4_HerramientasSCM_Enunciado.pdf` | Enunciado del trabajo práctico provisto por la cátedra. |

La definición de los Ítems de Configuración, la regla de nombrado y el criterio de Línea Base
—que constituyen la salida principal exigida por la consigna— se encuentran documentados en
[`DocumentacionGeneral/PlanDeConfiguracion.md`](../../DocumentacionGeneral/PlanDeConfiguracion.md),
dado que aplican a la totalidad del repositorio y no únicamente a este TP.
