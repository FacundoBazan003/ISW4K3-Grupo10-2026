# TIG2 - Frameworks Lean-Agile para el desarrollo de software

## Descripción

El Grupo 10 de 4K3 investigó cómo varios equipos pueden trabajar sobre un mismo producto con Large-Scale Scrum (LeSS). El póster presenta los principios de LeSS, la organización de un Sprint compartido y las diferencias entre LeSS y LeSS Huge. También compara LeSS con Nexus y SAFe y analiza en qué condiciones conviene adoptarlo.
