# TP2 - Requerimientos Agiles - User Stories y Estimaciones

## Descripción

Trabajo Práctico de la Unidad 2 (Gestión Lean-Ágil de Productos de Software), orientado a la
aplicación práctica de los conceptos de requerimientos ágiles y, en particular, de User Stories,
Épicas, Temas y MVP.

El trabajo se desarrolla sobre el dominio **EcoHarmony Park**: una aplicación móvil para un
bioparque que incluye mapa interactivo, horarios de alimentación de los animales, inscripción a
actividades y compra de entradas con pago a través de Mercado Pago. Los docentes representan a
los expertos del dominio y el grupo realiza preguntas para acordar el alcance del proyecto,
determinar las User Stories y definir sus pruebas de aceptación.

La salida exigida por la consigna comprende:

* Identificación de los roles principales.
* El MVP, explicando el alcance propuesto y justificando la inclusión de las User Stories
  seleccionadas y la exclusión de las restantes.
* User Stories identificadas con sus tarjetas completas.
* User Story canónica.
* User Stories estimadas.
