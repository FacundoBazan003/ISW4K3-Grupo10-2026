# TP3 - Requerimientos Ágiles - User Stories, Estimaciones y MVP

## Descripción

Trabajo Práctico de la Unidad 2 (Gestión Lean-Ágil de Productos de Software), orientado a la aplicación de los conceptos de requerimientos ágiles, User Stories, estimaciones y definición de un Producto Mínimo Viable (MVP).

El trabajo se desarrolla sobre el dominio **“Recircula tus prendas - Cuida el planeta”**, una plataforma de moda circular destinada a la compra y reventa de prendas usadas.

La solución incluye:

* Identificación de los roles principales.
* Definición y justificación del MVP.
* User Stories con sus tarjetas completas.
* User Story canónica.
* Estimación de las User Stories.
