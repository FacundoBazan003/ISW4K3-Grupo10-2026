# TP7 - Dinamica Scrum

## Descripción

Trabajo Práctico evaluable de la Unidad 2 (Gestión Lean-Ágil de Productos de Software), orientado
a internalizar los conceptos, prácticas y lineamientos del framework Scrum mediante dinámicas
colaborativas propuestas por los docentes, que asumen el rol de instructores.

El trabajo se desarrolla sobre el proyecto **Parque de diversiones**: construir prototipos de
atracciones en miniatura para una empresa de entretenimiento de Córdoba, a partir de una épica y
un conjunto de User Stories con su valor de negocio. Al final de cada sprint solo se aceptan las
atracciones que pasan la revisión de calidad y seguridad; las que quedan sin terminar continúan en
la siguiente iteración.

Durante la dinámica se ponen en práctica:

* Priorización y planificación de Sprint, definiendo el objetivo del sprint.
* Ejecución de Sprint.
* Daily Scrum Meeting.
* Sprint Review Meeting.
* Sprint Retrospective.
